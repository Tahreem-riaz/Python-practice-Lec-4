# 🐍 Lecture 04 — Dictionaries & Sets
A collection of Python practice exercises covering dictionaries, dictionary methods, sets, and set operations, along with a hands-on mini project.

This repository contains my practice work for **Lecture 04 of my Python learning journey**.
The lecture focuses on working with associative data structures and unique element collections using **dictionaries** and **sets**, accessing and modifying key-value pairs, understanding mutability and hashability rules, and applying set operations like union and intersection.

---

## 🎨 Topics Covered

### 1. Dictionaries
- Creating Dictionaries & Key-Value Pair Concept
- Dictionary Properties: Unordered, Mutable, No Duplicate Keys
- Accessing & Modifying Dictionary Data
- Working with Nested Dictionaries

### 2. Dictionary Methods
- Key & Value Extraction: `.keys()`, `.values()`, `.items()`
- Safe Fetching: `.get()`
- Bulk Updating & Insertion: `.update()`
